# Notebook display API

These functions configure HTML previews for `pyarrow.Table` values in notebook
environments. For task-oriented setup, see
[Configure notebook display](../guides/notebook_display.md).

      show_source: false

::: timeseries_table_format.disable_notebook_display

::: timeseries_table_format.load_notebook_display_config
